Conversational sales dashboard

Ask a question in French and get a full dashboard back: key figures, charts and detail, all filtered on the question. Follow-ups like “as a pie chart” or “top 5” change what's on screen.

  • The language model runs on the machine (Ollama) and only interprets the question. Every figure is computed by code, so the dashboard never shows a made-up number
  • 5 ready-made sections with 32 versioned visuals, deadline alerts by email, and a data-health check on the source sheet
  • 686 automated tests; one-file Docker installer that verifies the figures at the end

Python, FastAPI, React, DuckDB, Ollama, Docker, Google Sheets

Machine learning

Healthy Lifestyle Detector

A desktop app that estimates whether someone's habits point to a balanced diet, trained on a 125-student food survey, and shows which habits weigh most.

  • Balanced accuracy 0.61 and ROC AUC 0.70 against a 0.50 baseline, from 10× repeated 5-fold cross-validation
  • Version 1 couldn't learn: it mapped text labels onto numeric survey codes. I found the bug, rebuilt the features on the real scales and wrote tests
  • A modest result, reported honestly: small data, noisy label

Python, pandas, scikit-learn, PySide6, pytest

The stock, sales and profit dashboard I built for El Buteur, a small online shop selling football boots and jerseys in Tunisia.

  • Live KPIs: net profit, profit this month vs last, cash position, weekly courier payouts on the Saturday-to-Friday cycle
